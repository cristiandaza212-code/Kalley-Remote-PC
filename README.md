# Kalley Remote PC

Control remoto para Google TV por IP y código de vinculación, sin ADB. Interfaz RGB para Windows 11.

## Descargar
Abre **Actions > Compilar Kalley Remote PC > última ejecución exitosa > Artifacts > KalleyRemotePC-Windows**. Descarga el ZIP y extrae el único archivo `KalleyRemotePC.exe`. No requiere Python en el equipo de destino.

La primera vinculación requiere que PC y TV estén en la misma red. No se ha verificado todavía con un televisor Kalley real.
